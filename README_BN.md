# Bangladesh Bank-inspired website design demo

এটি বাংলাদেশ ব্যাংকের পাবলিক ওয়েবসাইটের বিভাগ ও তথ্য-লেআউট থেকে অনুপ্রাণিত একটি স্বতন্ত্র শিক্ষামূলক ডেমো। এটি বাংলাদেশ ব্যাংকের অফিসিয়াল ওয়েবসাইট নয়, অনুমোদিত নয়, এবং কোনো অফিসিয়াল লোগো বা লাইভ ডেটা ব্যবহার করে না।

## ফাইল
- `index.html` — হোমপেজের কাঠামো
- `style.css` — রেসপনসিভ ডিজাইন
- `script.js` — মোবাইল মেনু ও ডেমো সার্চ

## GitHub Pages-এ আপডেট
1. ZIP ফাইলটি ডাউনলোড করে Extract করুন।
2. `bb_redesign` ফোল্ডারের ভেতরের `index.html`, `style.css`, `script.js`, `README_BN.md` ফাইলগুলো রিপোজিটরির root-এ আপলোড করুন।
3. একই নামের পুরোনো ফাইল Replace/Overwrite করে Commit changes দিন।
4. GitHub Pages আপডেট হতে কয়েক মিনিট অপেক্ষা করুন, তারপর প্রকাশিত সাইট রিফ্রেশ করুন।

**গুরুত্বপূর্ণ:** নীতির হার, বিনিময় হার ও সংবাদ এখানে নমুনা হিসেবে দেওয়া। আর্থিক সিদ্ধান্তের জন্য ব্যবহার করবেন না। আসল ও সর্বশেষ তথ্যের জন্য https://www.bb.org.bd/en/ দেখুন।
